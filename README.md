# LocalFintechOCR

Offline-first card OCR toolkit for fintech apps. 100% on-device, zero cloud, zero per-scan cost.

## Installation (Swift Package Manager)

```swift
.package(url: "https://github.com/enjelhutasoit/LocalFintechOCR.git", from: "0.1.0")
```

```swift
import LocalFintechOCR

LuhnValidator.isValid("4111111111111111") // true
```

## Status

Pre-1.0. Public API may change between minor versions.
